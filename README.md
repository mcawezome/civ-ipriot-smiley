# Smiley (course starter code)

Class exercise · North Metropolitan TAFE · October 2024

A fork of the starter code for an object-oriented programming and IoT assessment. It draws smiley faces on a Raspberry Pi Sense HAT LED matrix and is used to practise abstraction, polymorphism, inheritance and encapsulation.

This fork has no commits of my own. The original instructions are in [djferg/civ-ipriot-smiley](https://github.com/djferg/civ-ipriot-smiley).
